0.9.45: Fixed subtitles never appearing in Overlay mode (since 0.9.42 on some Android TVs, e.g. Philips). Leaving the app fully releases the HDMI input so the TV's own HDMI screen does not stay black. If the picture drops during play the input is reopened once; if that fails the input picker and the Overlay suggestion are shown. The info panel shows the display mode, input state and device details.
